# Servants of the Way Digital Library | Berean Standard Bible

Standalone, text-only BSB Bible foundation built from an owner-supplied, publisher-provided USFM ZIP. Public-domain Bible translation.

**Coverage:** 66 books · 1,189 chapters · 31,086 main-text verses. Sixteen traditional verse positions absent from this publisher’s main text are preserved as omissions, with variant notes retained only in technical metadata.

- `index.html`: browse and select a book.
- `books/<slug>/site/index.html`: read book/chapter/verse.
- `data/bsb/<slug>/chapters/NN.json`: source-projected verse text.
- `data/bsb/catalog-<slug>.json`: book data plus missing verse positions.
- `data/bsb/route-map.json`: logical future external resource hook. No study integration built.
- `docs/EDITION.json`, `docs/SOURCE_LOCK.json`, `docs/RIGHTS_AND_PROVENANCE.md`: exact source, hashes and licensing.
- `docs/UPLOAD_GUIDE.md`: manually install numbered packs to GitHub repo root.

**Presented by the Servants of the Way Digital Library.** Technical provider URLs/source hashes are recorded in metadata only, not the Bible reader. The translation is public domain per publisher terms.

No scans, Strong’s, lexicons, dictionary, historical commentary, or English token-to-original-language alignments are embedded.
