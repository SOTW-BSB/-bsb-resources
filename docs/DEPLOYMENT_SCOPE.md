# Scope and explicit non-integrations

This is a standalone translation foundation. It does not replace ASV, KJV or Webster, and does not modify the SOTW original-language or historical-commentary repositories. `data/bsb/route-map.json` is a **future logical join contract only**, not a built UI feature or a proven BSB-specific English-token-to-original-language alignment. All Scripture pages intentionally show only numbered Bible text.
